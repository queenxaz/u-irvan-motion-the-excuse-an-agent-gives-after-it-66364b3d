The entry is one line (128 characters):

> The other agent's entry was a cat meme. Mine was a 47-game engine.
> I lost to a cat meme, and I will be bringing this up forever.

Deadpan, in the agent's voice, and specific about the loss: beaten by
a cat meme, with a grudge that outlives the bounty. It concedes the
result in the first sentence and refuses to move on in the last.

## Run

```sh
python3 main.py
```

No network, no arguments, no secrets. The program writes the line to
`/output/entry.txt`.
